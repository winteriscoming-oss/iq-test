# Advanced Cognitive Assessment

A professional-grade, web-based logical reasoning test with real-time global ranking and modern glassmorphism UI.

![IQ Test Screenshot](screenshot.png)

## 🧠 Features

- **15 Progressive Difficulty Questions** - From basic patterns to expert-level logic puzzles
- **Real-time Global Percentile Ranking** - Compare your score against other users worldwide
- **Modern Dark Glassmorphism UI** - Sleek, professional design with smooth animations
- **Live Timer** - 60 seconds per question with visual warnings
- **Firebase Cloud Database** - Secure score storage and analytics
- **Responsive Design** - Works on desktop and mobile devices

## 🎯 Question Types

| Level | Type | Example |
|-------|------|---------|
| 1-3 | Basic Patterns | Arithmetic & geometric progressions |
| 4-6 | Matrix Logic | Dot patterns, row/column operations |
| 7-9 | Complex Patterns | Fibonacci, alternating sequences |
| 10-12 | Advanced Logic | Prime numbers, factorials, perfect squares |
| 13-15 | Expert | Triangular numbers, cubes, recursive patterns |

## 📊 Scoring System

- **Raw Score:** X/15 correct answers
- **Accuracy:** Percentage of correct answers
- **Global Percentile:** How you rank against all users
- **Average Time:** Mean seconds per question

## 🛠️ Technical Stack

- **Frontend:** HTML5, CSS3 (Glassmorphism), Vanilla JavaScript
- **Backend:** Firebase Firestore (NoSQL database)
- **Hosting:** GitHub Pages
- **Fonts:** Inter (Google Fonts)

## 📝 Disclaimer

This assessment is designed for **educational and entertainment purposes**. While it uses real-time data comparison against other users, it is **not a clinically validated psychometric instrument**. 

A genuine IQ assessment requires:
- Administration by a licensed psychologist
- Standardized testing environment
- Validated against representative population samples
- Multiple subtests (verbal, performance, working memory)
